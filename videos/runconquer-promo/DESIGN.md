# DESIGN.md — RunConquer Promo Video

## Brand
RunConquer / Run & Conquer — Lauf-App für Gebietseroberung in der eigenen Stadt.
Mood: Dark Premium, High-Energy Gaming, Urban.

## Palette
| Token | Hex | Verwendung |
|---|---|---|
| bg | #09090F | Basis-Hintergrund aller Szenen |
| surface | #1A1A26 | Karten, Rows |
| surface-2 | #0D0D18 | Szene 4 Hintergrund |
| accent | #E8FF47 | Primärer Akzent (Gelb-Grün), Headlines, Glows |
| fg | #F0F0F8 | Haupttext |
| muted | #6B6B82 | Labels, Meta-Text |
| danger | #FF4D6D | Conquest-Badge |
| health | #10B981 | Reserviert (nicht verwenden) |
| cyan | #00D4FF | Reserviert (nicht verwenden) |

## Typografie
- Display: **Bebas Neue** (700) — Headlines, Zahlen, Buttons
- Body: **Poppins** (400, 600) — Labels, Meta, Sub-Texte

## Größen (Portrait 1080×1920)
- Hero-Headline: 160-220px (Bebas Neue)
- Sub-Headline: 80-120px (Bebas Neue)
- Labels: 22-28px (Poppins, letter-spacing 4-6px)
- Body: 24-32px (Poppins)
- Data: 100-140px (Bebas Neue)

## Corner Radius
- Buttons: 50px (pill)
- Karten: 24px
- Kleine Chips: 50px

## Don'ts
- Kein cyan-on-dark als Hauptakzent
- Kein purple-to-blue Gaming-Gradient
- #E8FF47 ist der einzige Hauptakzent — kein cyan/lila als zweite Akzentfarbe
- Keine vollflächigen linearen Gradienten auf dunklem Bg (H.264-Banding)
- Keine zentrierten gleichgewichtigen Layouts — Lead the eye
